# Curriculum — управление набором букв и учебной последовательностью

Дата: 2026-08-19

## 1. Назначение

Этот документ задаёт правила, по которым буквы попадают в уровни и упражнения. Он отделяет учебное содержание от кода.

Полный порядок 33 букв пока сознательно не фиксируется как окончательный. До расширения на весь алфавит он должен быть подтверждён домашним тестированием и, при необходимости, профильным специалистом.

## 2. Что является единицей curriculum

Для каждой буквы хранится запись:

- `symbol` — визуальный символ;
- `spokenName` — название для TTS;
- `stageIntroduced` — уровень/этап введения;
- `confusableWith` — потенциально похожие буквы;
- `preferredDistractors` — подходящие варианты ответа;
- `avoidEarlyPairingWith` — буквы, которые не стоит вводить одновременно на раннем этапе;
- `enabled` — доступна ли буква в текущей версии curriculum.

Позже этот набор должен храниться в централизованной конфигурации, а не быть разбросан по UI.

## 3. Начальный пилот

### Level 1

Буквы: `А`, `М`.

Цель: проверить основной UX, TTS, запись статистики, retry и реакцию на ошибку.

На этом этапе правильность педагогического порядка полного алфавита не проверяется.

## 4. Правила добавления новой буквы

Новая буква добавляется только если:

- предыдущий набор технически работает;
- нет очевидной проблемы TTS;
- ребёнок понимает механику упражнения;
- LearningEngine способен продолжать показывать старые буквы;
- новая буква не открывается просто за количество кликов.

Обычно добавлять по одной новой букве за уровень.

## 5. Похожие и путаемые буквы

Система должна различать два понятия:

### Потенциально похожие

Пары/группы, которые заранее можно считать визуально близкими или часто путаемыми и использовать осторожно.

Примеры для отдельной проверки curriculum, а не как окончательный список:

- `Н / П`;
- `Ш / Щ`;
- `Ь / Ъ`;
- `И / Й`;
- `В / Б`;
- `Р / В` при быстром распознавании.

### Фактически путаемые

Пары, которые реально возникают в данных конкретного ребёнка.

Фактическая confusion matrix имеет приоритет над заранее составленным списком.

## 6. Distractors — неправильные варианты ответа

Неправильные варианты должны формироваться осмысленно.

На раннем этапе:

- не показывать только один и тот же набор в одном и том же расположении;
- перемешивать позиции ответов;
- не создавать ситуацию, когда правильный ответ угадывается по месту;
- часть distractors брать из хорошо знакомых букв;
- при тренировке конкретной путаницы использовать фактически путаемую пару.

При двух вариантах вероятность случайного угадывания 50%, поэтому выводы об освоении нельзя делать по 1–2 вопросам.

## 7. TTS-названия

Для каждой буквы хранить `spokenName` явно.

Перед включением буквы в основной curriculum её название нужно проверить на реальном устройстве.

Если TTS произносит название неудовлетворительно, возможны варианты:

1. скорректировать строку для TTS;
2. использовать заранее записанное локальное аудио взрослого;
3. временно исключить букву из автоматического голосового режима.

Решение фиксировать в `DECISIONS.md`, если оно влияет на продукт.

## 8. Версионирование curriculum

Curriculum должен иметь версию, например:

`curriculumVersion = 1`

Версию повышать, если изменяется:

- порядок введения букв;
- TTS-name;
- набор distractors;
- правила формирования уровней.

Поправка опечатки в документации не требует повышения версии.

## 9. Переход к полному алфавиту

До M5 необходимо:

1. Зафиксировать полный порядок 33 букв.
2. Проверить все `spokenName` на целевом устройстве.
3. Определить начальные группы визуально похожих букв.
4. Проверить, что порядок не создаёт ненужной перегрузки похожими символами подряд.
5. Определить число вариантов ответа по мере роста уровня.
6. Провести несколько реальных сессий и скорректировать curriculum по данным.

## 10. Что curriculum НЕ должен решать

Curriculum определяет содержание и последовательность, но не решает:

- какая буква должна появиться следующей внутри конкретной сессии — это LearningEngine;
- когда буква считается освоенной — это LearningPolicy;
- игровую награду — это UX/Game layer.
