# Local Git Sync — Android Studio ↔ GitHub

Цель: не потерять изменения, сделанные ChatGPT в GitHub, когда локальная копия Android Studio устарела.

## Перед любой новой локальной работой

Если нет незакоммиченных изменений:

1. `Git` → `Pull`.
2. Убедиться, что Pull завершился без ошибки.
3. Только после этого начинать локальные изменения.

Если есть незакоммиченные изменения — сначала сделать обычный commit, затем Pull. При конфликте не использовать Force Push.

## После законченного локального шага

1. `Git` → `Commit`.
2. Выбрать только относящиеся к задаче файлы.
3. Ввести понятное сообщение.
4. `Commit and Push`.
5. Убедиться, что Push успешен.

## Запрещено

- не использовать `Force Push` в `main`;
- не делать reset/rebase с потерей удалённых commit без осознанного решения;
- не продолжать работу после сообщения `non-fast-forward` путём Force Push;
- не использовать Android Studio Agent только для обычного commit/push/pull.

## Если Push отклонён

Не нажимать Force Push.

1. Скопировать текст ошибки.
2. Передать его Gemini Web.
3. Gemini Web маршрутизирует проблему: простое действие владельца, ChatGPT или Android Studio Agent только если действительно требуется локальная диагностика.

## Почему это важно

ChatGPT может менять GitHub между вашими локальными сессиями. Поэтому локальный Android Studio проект перед началом следующей работы должен получить свежий `Pull`.

GitHub — источник истины для общей версии проекта; локальная копия — рабочая среда для Android runtime.
