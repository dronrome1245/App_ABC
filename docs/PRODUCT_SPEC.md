# Product specification — App_ABC MVP

## Проблема

Ребёнку трудно быстро связать визуальный образ русской буквы с её названием. Нужен короткий повторяемый тренажёр по принципу тренажёра нот: маленький набор → активные ответы → постепенное расширение → постоянное повторение старого материала.

Приложение не ставит диагнозы и не заменяет обучение со специалистом. Это инструмент домашней практики и наблюдения за динамикой.

## Главный сценарий ребёнка

1. Открыть приложение.
2. Нажать «Продолжить».
3. Пройти короткий уровень/сессию.
4. Получать новые буквы постепенно.
5. Старые буквы продолжают встречаться.
6. После занятия увидеть положительный результат и прогресс.
7. При желании сразу начать ещё одну тренировку.

## Главный сценарий взрослого

1. Нажать «Родителям».
2. Решить простой арифметический Parental Gate по D023.
3. Открыть Parent Dashboard / Statistics.
4. Посмотреть прогресс по всем 33 буквам.
5. Увидеть слабые буквы и частые путаницы.
6. При необходимости запустить тренировку трудных букв или вручную выбрать набор букв на последующих этапах M3.
7. При необходимости сбросить прогресс с подтверждением после реализации Settings.

Parental Gate является UX-разделением взрослого и детского потоков; он не подменяет общий privacy/compliance review.

## Режимы MVP

### Путь / уровни

По D024 целевая структура состоит из 8 игровых уровней и в совокупности покрывает все 33 русские буквы. Runtime после M2 пока реализует Levels 1–3 (`А/М`, `О/У`, `С/Н`); Levels 4–8 реализуются отдельным этапом M3.2 после внесения точной owner-approved матрицы состава уровней.

Старые буквы всегда остаются в пуле повторения.

### Трудные буквы

Автоматически показывает буквы с высоким уровнем ошибок/замедленных ответов. Позволяет запустить тренировку слабого набора плюс небольшое количество хорошо знакомых букв для сравнения.

### Выбрать буквы

Взрослый может вручную выбрать несколько букв для отдельной тренировки. Реализация относится к последующим slice M3.

### Статистика / Parent mode

M3.1 вводит Parent Dashboard со сводными показателями:

- освоено букв `X из 33`;
- число завершённых тренировочных сессий;
- общая точность;
- сетка всех 33 букв со статусами `NOT_STARTED / INTRODUCED / PRACTICING / MASTERED`;
- детализация по букве: точность, количество показов, состояние освоения, среднее время ответа.

Дальнейшие M3 slice добавят recent accuracy, confusion matrix, список трудных букв, историю и настройки. Если данных недостаточно, показывать `Не начато`/`Недостаточно данных`, а не искусственно плохую оценку.

## Основное упражнение MVP

### «Услышь название → выбери букву»

Приложение произносит название целевой буквы. На экране несколько крупных букв. Ребёнок выбирает нужную.

Текущий учебный цикл остаётся фиксированным: 10 вопросов, adaptive target selection, retry/delayed checks LearningPolicy v3 и level unlock `>=80%` / `8 из 10`.

## Будущий режим «Увидел → назови»

Автоматическая проверка требует распознавания речи. Это отдельный модуль и не должно задерживать основной MVP.

## Curriculum / 8 уровней

Канонический русский алфавит для статистики и полного Curriculum:

`А Б В Г Д Е Ё Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ъ Ы Ь Э Ю Я`.

D024 утверждает 8 уровней и покрытие всех 33 букв. Точная матрица Levels 4–8 должна быть импортирована из owner decision перед M3.2; M3.1 не изобретает отсутствующий в task packet состав.

## Long-term retention

D025 задаёт 7-дневный горизонт long-term retention для `MASTERED`: при отсутствии успешного подтверждения в течение 7 суток буква должна снова считаться требующей проверки. M3.1 не меняет LearningPolicy v3; фактическое влияние decay на веса/состояния реализуется только отдельной versioned политикой и time-based тестами.

Суточной блокировки приложения нет.

## Сессия

Целевая продолжительность — примерно 3–7 минут. Каждая сессия имеет `sessionId`, чтобы анализировать динамику и реальные интервалы между тренировками.

## Ошибка

Спокойно показать правильную букву, при необходимости повторить название и вернуть её позднее по retry policy. Не использовать потерю жизни, громкий негативный звук или обнуление прогресса.

## Данные и измеримость

Каждая Attempt должна позволять рассчитать метрики из `SUCCESS_METRICS.md`.

Минимально сохранять:

- targetLetter;
- selectedLetter;
- isCorrect;
- responseTimeMs;
- timestamp;
- sessionId;
- levelId;
- exerciseType;
- версии LearningPolicy/Curriculum.

Parent Dashboard M3.1 агрегирует существующие Room schema 2 данные; новая таблица для него не требуется.

## Privacy

MVP локальный. По умолчанию не использовать backend, аккаунты, аналитику, рекламу и сохранение аудио. Подробно: `PRIVACY_RELEASE.md`.

## Не входит в текущий M3.1

- реализация Levels 4–8;
- 27 новых audio assets;
- изменение LearningPolicy v3 под D025;
- новые Room tables/schema;
- speech recognition;
- backend/analytics/ads.
