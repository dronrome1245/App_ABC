# Product specification — App_ABC MVP

## Проблема

Ребёнку трудно быстро связать визуальный образ русской буквы с её названием. Нужен короткий повторяемый тренажёр по принципу тренажёра нот: маленький набор → активные ответы → постепенное расширение → постоянное повторение старого материала.

Приложение не ставит диагнозы и не заменяет обучение со специалистом. Это инструмент домашней практики и наблюдения за динамикой.

## Главный сценарий

1. Открыть приложение.
2. Нажать «Продолжить».
3. Пройти короткий уровень/сессию.
4. Получать новые буквы постепенно.
5. Старые буквы продолжают встречаться.
6. После занятия увидеть положительный результат и прогресс.
7. При желании сразу начать ещё одну тренировку.

## Режимы MVP

### Путь / уровни

Уровень 1 начинается с двух букв. Далее обычно добавляется по одной новой букве, при этом старые остаются в пуле повторения.

### Трудные буквы

Автоматически показывает буквы с высоким уровнем ошибок/замедленных ответов. Позволяет запустить тренировку слабого набора плюс небольшое количество хорошо знакомых букв для сравнения.

### Выбрать буквы

Родитель может вручную выбрать несколько букв для отдельной тренировки.

### Статистика

Для каждой буквы: число попыток, процент правильных, последние результаты, время ответа, уровень освоения и наиболее частые путаницы.

## Основное упражнение MVP

### «Услышь название → выбери букву»

Приложение произносит название целевой буквы. На экране несколько крупных букв. Ребёнок выбирает нужную.

В первом вертикальном срезе — 2 варианта. Позднее количество вариантов можно увеличить.

## Будущий режим «Увидел → назови»

Автоматическая проверка требует распознавания речи. Это отдельный модуль и не должно задерживать основной MVP.

## Уровни

- Уровень 1: две буквы.
- Последующие уровни обычно добавляют по одной новой.
- Прохождение уровня не удаляет старые буквы из тренировок.
- Новая буква может открываться в тот же день.
- Важно не только количество правильных ответов подряд, но и правильный ответ после промежутка из других заданий.
- Повторное прохождение разрешено всегда.

Точный порядок 33 букв будет согласован отдельно. Для первого прототипа достаточно `А` и `М`.

## Сессия

Целевая продолжительность — примерно 3–7 минут. После рекомендуемого объёма показать экран завершения и кнопки `Закончить` и `Ещё потренироваться`. Суточной блокировки нет.

## Ошибка

Спокойно показать правильную букву, при необходимости повторить название и вернуть её позднее. Не использовать потерю жизни, громкий негативный звук или обнуление прогресса.

## Не входит в MVP

Звуки букв, фонематические упражнения, слоги, слова, чтение, рукописные буквы, рисование, iOS, аккаунты и облачная синхронизация.
