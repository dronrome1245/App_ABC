# Product specification — App_ABC MVP

## Проблема

Ребёнку трудно быстро связать визуальный образ русской буквы с её названием. Нужен короткий повторяемый тренажёр по принципу тренажёра нот: маленький набор → активные ответы → постепенное расширение → постоянное повторение старого материала.

Приложение не ставит диагнозы и не заменяет обучение со специалистом. Это инструмент домашней практики и наблюдения за динамикой.

## Главный сценарий ребёнка

1. Открыть приложение.
2. Нажать «Продолжить».
3. Пройти короткий уровень/сессию.
4. Получать новые буквы постепенно.
5. Старые буквы продолжают встречаться.
6. После занятия увидеть положительный результат и прогресс.
7. При желании сразу начать ещё одну тренировку.

## Главный сценарий взрослого

1. Открыть Parent mode / Statistics.
2. Посмотреть прогресс по буквам.
3. Увидеть слабые буквы и частые путаницы.
4. При необходимости запустить тренировку трудных букв.
5. Вручную выбрать набор букв, если требуется.
6. Изменить допустимые настройки сессии.
7. При необходимости сбросить прогресс с подтверждением.

Сложная авторизация взрослого для семейного MVP не требуется. Способ входа в Parent mode должен быть простым, но не занимать центральное место в детском интерфейсе.

## Режимы MVP

### Путь / уровни

Уровень 1 начинается с двух букв. Далее обычно добавляется по одной новой букве, при этом старые остаются в пуле повторения.

### Трудные буквы

Автоматически показывает буквы с высоким уровнем ошибок/замедленных ответов. Позволяет запустить тренировку слабого набора плюс небольшое количество хорошо знакомых букв для сравнения.

### Выбрать буквы

Взрослый может вручную выбрать несколько букв для отдельной тренировки.

### Статистика / Parent mode

Для каждой буквы показывать по мере накопления данных:

- число попыток;
- recent accuracy;
- последние результаты;
- медианное/типичное время ответа;
- уровень освоения;
- наиболее частые путаницы;
- наличие delayed/inter-session подтверждений, если данных достаточно.

Если данных недостаточно, показывать `Недостаточно данных`, а не искусственно плохую оценку.

## Основное упражнение MVP

### «Услышь название → выбери букву»

Приложение произносит название целевой буквы. На экране несколько крупных букв. Ребёнок выбирает нужную.

В первом вертикальном срезе — 2 варианта. Позиции вариантов должны меняться между вопросами, чтобы уменьшить запоминание расположения. Позднее количество вариантов можно увеличить.

## Будущий режим «Увидел → назови»

Автоматическая проверка требует распознавания речи. Это отдельный модуль и не должно задерживать основной MVP.

## Уровни

- Уровень 1: две буквы.
- Последующие уровни обычно добавляют по одной новой.
- Прохождение уровня не удаляет старые буквы из тренировок.
- Новая буква может открываться в тот же день.
- Важно не только количество правильных ответов подряд, но и правильный ответ после промежутка из других заданий.
- Повторное прохождение разрешено всегда.
- Игровой прогресс не является единственной мерой знания.

Полный порядок 33 букв управляется `CURRICULUM.md` и отдельной версией curriculum. Для первого прототипа достаточно `А` и `М`.

## Сессия

Целевая продолжительность — примерно 3–7 минут. После рекомендуемого объёма показать экран завершения и кнопки `Закончить` и `Ещё потренироваться`. Суточной блокировки нет.

Каждая сессия должна иметь `sessionId`, чтобы можно было анализировать динамику и реальные интервалы между тренировками.

## Ошибка

Спокойно показать правильную букву, при необходимости повторить название и вернуть её позднее. Не использовать потерю жизни, громкий негативный звук или обнуление прогресса.

## Данные и измеримость

Каждая Attempt должна позволять рассчитать метрики из `SUCCESS_METRICS.md`.

Минимально сохранять:

- targetLetter;
- selectedLetter;
- isCorrect;
- responseTimeMs;
- timestamp;
- sessionId;
- levelId;
- exerciseType;
- версии учебной политики/curriculum, когда они появятся.

## Privacy

MVP локальный. По умолчанию не использовать backend, аккаунты, аналитику, рекламу и сохранение аудио. Подробно: `PRIVACY_RELEASE.md`.

## Не входит в MVP

Звуки букв, фонематические упражнения, слоги, слова, чтение, рукописные буквы, рисование, iOS, аккаунты, облачная синхронизация, реклама, медицинская диагностика.
