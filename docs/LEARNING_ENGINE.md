# Learning engine — алгоритм обучения

## Главный принцип

Приложение должно тренировать извлечение из памяти, а не только многократный показ одной буквы. После ошибки букву нужно вернуть через несколько других вопросов. Старые буквы должны периодически появляться после открытия новых уровней.

## Состояния буквы

- `NEW`
- `LEARNING`
- `FAMILIAR`
- `STABLE`

Это внутренняя игровая метрика, а не медицинская оценка.

## Данные

### Attempt

`id`, `timestamp`, `levelId`, `exerciseType`, `targetLetter`, `selectedLetter`, `isCorrect`, `responseTimeMs`.

### LetterProgress

`totalAttempts`, `correctAttempts`, `recentAccuracy`, `recentMedianResponseTime`, `consecutiveCorrect`, `lastSeenAt`, `lastErrorAt`, `masteryState`.

### Confusion

Для каждой ошибки увеличивать счётчик `targetLetter -> selectedWrongLetter`.

## Проблемная буква

В первой реализации букву можно считать проблемной, если после минимум 5 попыток recent accuracy ниже 80%, есть две и более недавние ошибки, повторяется одна и та же путаница или время ответа заметно выше личной медианы.

Пороги должны храниться централизованно как конфигурация.

## Выбор следующего вопроса

1. Пул = буквы текущего уровня + ранее изученные.
2. Повысить вес новой буквы, букв с недавними ошибками, слабых и давно не появлявшихся.
3. Сильные буквы сохраняют ненулевой вес.
4. Не давать одну цель слишком много раз подряд.

Ориентир при достаточном пуле: около 50% новые/слабые, 30% обычное повторение, 20% сильные старые.

## После ошибки

1. Показать корректный ответ.
2. Поставить target в `retryQueue`.
3. Дать примерно 2–4 других задания, если пул позволяет.
4. Снова спросить target.
5. Позднее вернуть его в обычный поток.

## Открытие уровня

Не требуется ждать следующего дня. Для MVP: выполнен минимальный объём, recent accuracy примерно 85% или выше, а каждая новая буква правильно распознана минимум дважды после интервала из других вопросов.

## Тренировка слабых

Экран сортирует буквы по слабости. В специальной тренировке примерно 70–80% вопросов приходятся на выбранные слабые буквы, остальные — на хорошо знакомые контрольные буквы.

## Unit tests

Проверить: старые буквы не исчезают; ошибка возвращает target; retry не бесконечен; нет длинных серий одной цели; слабая буква получает больший вес; confusion matrix обновляется; история не стирается.
