# UX и игровая оболочка

## Решение

Используем игровую форму, но не превращаем приложение в сложную игру. Игровая оболочка отвечает за мотивацию, а LearningEngine — за то, какие буквы повторяются.

## Уровни

Визуально можно сделать путь из карточек/кружков: уровень 1 — `А М`, дальше добавляется по одной букве. Пройденный уровень можно запускать повторно.

## Награды MVP

Достаточно 1–3 звёзд, короткой анимации открытия уровня и простых достижений вроде «5 букв», «10 букв», «20 букв».

Не нужны в первой версии монеты, магазин, инвентарь, ежедневные сундуки, рейтинг и реклама.

## Звёзды

- 1 звезда — уровень завершён;
- 2 звезды — достигнута целевая точность;
- 3 звезды — буквы уровня достигли нужного mastery-критерия.

Повторное прохождение позволяет добрать звёзды.

## Ошибки

Не использовать «НЕПРАВИЛЬНО!» на весь экран, потерю жизни, обнуление серии и громкий негативный звук. Нужна короткая коррекция и продолжение.

## Темп

Экран упражнения: один вопрос, крупные варианты, минимум текста, крупные зоны нажатия, кнопка повторить голос, быстрый переход дальше.

## Сессия

После 3–7 минут или целевого числа вопросов показать «Отличная тренировка!» и кнопки `Закончить` / `Ещё потренироваться`. При следующем входе всё снова доступно.

## Принцип визуальных акцентов для детей без навыка чтения

На экране итогов сессии (`ResultScreen`) стиль кнопки является самостоятельным визуальным сигналом и должен помогать ребёнку выбрать педагогически предпочтительное продолжение даже без чтения текста. Правило зафиксировано в D027.

| Результат сессии | Primary — Filled | Secondary — Outlined |
| --- | --- | --- |
| Успех (`passed == true`) | `К выбору уровней / Далее` | `Повторить` |
| Неудача (`passed == false`) | `Попробовать снова` | `К выбору уровней` |

`Filled` всегда используется для рекомендуемого следующего действия. `Outlined` используется для допустимой альтернативы. Поэтому визуальный акцент не закрепляется навсегда за одной и той же командой: он меняется в зависимости от результата сессии.

## Статистика — для взрослого

Показывать освоенные/изучаемые/трудные буквы, точность, время ответа, частые путаницы, кнопку `Тренировать трудные` и ручной выбор букв.
