# Audio Distribution Gate

## Статус

**HOME / PERSONAL USE ONLY для временного Audio Pack v2.**

Репозиторий может использоваться как приватный семейный проект для обучения ребёнка. В рамках такого режима допускается временно использовать аудиоматериалы, выбранные по качеству для домашнего применения, если их источник и условия использования позволяют такое личное использование.

## Обязательное правило перед распространением

**STOP: перед любой передачей, публикацией или распространением приложения текущий временный Audio Pack v2 необходимо заменить на аудиопакет с заранее подтверждённым правом распространения в составе приложения.**

Под распространением здесь понимаются, в частности:

- публикация APK/AAB в Google Play, RuStore или другом магазине;
- размещение APK/AAB на сайте, в облаке или публичном репозитории;
- передача APK/AAB другим людям вне домашнего использования;
- перевод репозитория в публичный режим, если в нём присутствуют ограниченные аудиоассеты;
- передача сборки заказчику, организации, школе, детскому центру и т.п.

Приватность GitHub-репозитория сама по себе не меняет лицензию исходных аудиоматериалов и не даёт дополнительных прав на их распространение.

## Допустимые домашние варианты

### 1. GCompris Russian alphabet recordings

- человеческая запись русского алфавита;
- полный набор 33 букв;
- в исходном наборе указан автор Alexey V. Lubimov;
- лицензия исходных записей обозначена как GPL;
- допустим как временный личный/домашний кандидат;
- **не считать автоматически разрешённым production-аудиопакетом App_ABC**;
- перед распространением приложения заменить либо отдельно провести полноценную лицензионную проверку выбранной схемы распространения.

### 2. Vitaly Volkov / Wikimedia Commons

- человеческая запись носителя русского языка;
- исходник `RU-alfavit.ogg` и отдельные записи букв доступны через Wikimedia Commons;
- источник указан под CC BY 1.0;
- эта лицензия допускает распространение при соблюдении атрибуции;
- однако для текущего проекта действует более строгое внутреннее правило: **если запись используется как временный домашний Audio Pack v2, перед публичным релизом всё равно остановиться и отдельно принять решение о production-аудио**.

### 3. Собственная семейная запись

Запись собственного голоса или голоса члена семьи с его согласия — предпочтительный вариант для полностью приватной домашней версии. Перед распространением приложения всё равно требуется отдельно определить права на запись и получить необходимое согласие на публичное использование.

### 4. Android TextToSpeech

Можно оставить системный TTS как fallback без включения сторонних записей в репозиторий. Качество произношения коротких названий букв должно проверяться отдельно; TTS не считается заменой принятому Audio Pack v2.

## Release checklist

Перед любым распространением владелец проекта должен явно подтвердить все пункты:

- [ ] временные HOME-ONLY аудиоассеты удалены из `app/src/main/res/raw`;
- [ ] выбран новый production-аудиопакет или подтверждена допустимость конкретного существующего источника;
- [ ] проверены лицензия, авторство, условия модификации и распространения;
- [ ] при необходимости добавлена атрибуция и `THIRD_PARTY_NOTICES`;
- [ ] все 33 названия букв прослушаны человеком и соответствуют Curriculum;
- [ ] выполнен device smoke для 33 букв;
- [ ] владелец проекта отдельно разрешил распространение.

Пока этот checklist не закрыт, статус distribution должен считаться **BLOCKED BY AUDIO LICENSE GATE**.
