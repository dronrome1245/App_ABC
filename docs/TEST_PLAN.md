# Test plan

## M1 acceptance test

Владелец должен суметь:

1. открыть приложение;
2. нажать «Начать»;
3. услышать запрос буквы;
4. повторить запрос;
5. нажать А или М;
6. увидеть спокойную реакцию;
7. пройти 10 вопросов;
8. увидеть X/10;
9. закрыть приложение;
10. открыть снова и убедиться, что история сохранена.

## После домашнего теста фиксировать

Размер кнопок, слышимость и корректность TTS, скорость смены вопроса, понятность ошибки, угадывание по позиции кнопок, нужность случайной перестановки и комфортное число вопросов.

## Автотесты минимум

LearningEngine не выдаёт длинную серию; retry возвращает ошибочную букву; Attempt сохраняется; confusion pair формируется правильно; старые данные не удаляются.
