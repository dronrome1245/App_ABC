# AUDIO_DISTRIBUTION_NOTICE.md

## ВАЖНО: домашний аудиопак нельзя распространять

Этот документ является обязательным release blocker для Audio Pack v2 / D027.

Если для локальной домашней сборки используется аудиопак, лицензия которого не подтверждена как совместимая с предполагаемым способом распространения приложения, такой пакет считается **HOME-ONLY**.

## Текущее состояние

- Репозиторий `dronrome1245/App_ABC` подтверждён GitHub API как **private** перед добавлением HOME-ONLY файлов.
- В ветке `feature/audio-pack-v2-d027` установлены `33 / 33` GCompris `sound_letter_<token>_v2.ogg`.
- `HOME_ONLY_AUDIO_PACK = true`.
- Пакет принят владельцем только для личного домашнего обучения.
- Device audio smoke для 33 букв ещё требуется перед закрытием AUDIO-02 для домашнего использования.
- Distribution gate остаётся активным независимо от результата домашнего smoke.

### Правило

- `HOME_ONLY_AUDIO_PACK = true` означает: приложение можно собирать и использовать только локально для личного домашнего использования.
- HOME-ONLY аудиофайлы **нельзя коммитить в публичный репозиторий**.
- До публикации, передачи или иного распространения APK/AAB, исходного кода с аудио либо готового приложения HOME-ONLY аудиопак должен быть полностью заменён на пакет с подходящей лицензией.
- После замены необходимо отдельно проверить лицензию, атрибуцию, соответствие 33 названий букв и выполнить device audio smoke.
- Пока эта проверка не завершена, публичный релиз должен считаться заблокированным.

## GCompris

Русский набор GCompris (`voices/ru/alphabet`) записан Alexey V. Lubimov и помечен в исходном README как GPL. Для App_ABC он может рассматриваться как **локальный домашний референс/пакет**, но не должен попадать в публичный репозиторий или публичный APK без отдельного решения по совместимости лицензий и выполнению требований GPL.

Для практического процесса App_ABC действует более строгое правило: **если GCompris используется в домашней сборке, перед любым распространением заменить весь этот аудиопак**.

## Release gate

Перед любым публичным или стороннему получателю релизом проверить:

1. В `app/src/main/res/raw/` нет HOME-ONLY аудио.
2. Все `sound_letter_<token>_v2` имеют подтверждённый источник и лицензию.
3. Выполнены обязательные attribution/NOTICE требования.
4. В PR/релизе явно указано, какой production-аудиопак используется.
5. Выполнены CI и физический audio smoke для всех 33 букв.

**Запрещено считать AUDIO-02 готовым к распространению, если используется HOME-ONLY пакет.**
