# Эксперимент: распознавание названия буквы ребёнком

## Зачем

Будущий режим: приложение показывает `М`, ребёнок произносит «эм», приложение определяет, совпадает ли распознанное название с целевой буквой.

## Почему отдельно

Ответы очень короткие: `а`, `бэ`, `вэ`, `эм`, `эн`, `эль` и т.д. Распознавание короткой детской речи нужно отдельно проверить, чтобы ошибка ASR не превращалась в ложную учебную ошибку.

## Первая реализация

Использовать Android `SpeechRecognizer` с locale `ru-RU`.

- если доступен on-device recognizer, предпочитать его;
- иначе сетевой recognizer допускается только после понятного сообщения взрослому;
- `RECORD_AUDIO` запрашивать только при входе в голосовой режим.

## Нормализация

Для каждой буквы хранить допустимые варианты, например:

```text
М: ["м", "эм"]
Н: ["н", "эн"]
Л: ["л", "эль"]
```

Нормализовать регистр, пробелы, пунктуацию и служебные слова вроде «буква». Не использовать слишком широкое fuzzy-сравнение.

## Три исхода

- `CORRECT`
- `WRONG` — распознана другая уверенная буква
- `NOT_RECOGNIZED` — система не уверена / ничего не распознала

`NOT_RECOGNIZED` не считается учебной ошибкой.

## Пока это эксперимент

- не использовать voice attempts для открытия уровней;
- хранить их отдельно;
- не сохранять аудиофайлы;
- дать кнопку `Повторить`;
- дать взрослому возможность увидеть raw recognition result.

## Проверка качества

Сделать тестовый экран: выбрать букву, выполнить несколько произнесений, показать результаты, считать false rejection/false acceptance и проверить в тишине и бытовом шуме.

Только после проверки на реальной детской речи решать, какие буквы можно автоматически оценивать.
