## Продуктовая стратегия

Сначала делается семейный пилот. Решение о публичном продукте принимается после реального использования и проверки метрик.

## Зафиксировано

- тренируем названия букв, не звуки;
- стартуем только с Android;
- печатные заглавные русские буквы;
- обучение строится как уровни;
- каждый следующий уровень расширяет набор, но старые буквы продолжают повторяться;
- проблемные буквы автоматически определяются по статистике и доступны для отдельной тренировки;
- хранится карта путаницы `целевая буква → выбранная неправильная буква`;
- цель обычной сессии — около 3–7 минут;
- после завершения рекомендуемой сессии приложение не блокируется;
- рисование исключено из MVP;
- слоги/слова исключены из MVP;
- распознавание произнесённого названия буквы делается отдельным экспериментальным модулем после основного цикла;
- основной критерий успеха — не количество уровней, а динамика accuracy/response time/confusion/delayed retention;
- LearningPolicy и Curriculum должны версионироваться;
- `main` после появления кода должен оставаться рабочим;
- публичный GitHub не должен содержать реальные персональные данные, аудио, базы статистики и секреты.

## Ближайшая цель

Получить первый debug-build, который можно запустить на реальном Android-телефоне.

### Вертикальный срез M1

1. Создать Android-проект.
2. Главный экран с кнопкой «Начать».
3. Уровень 1 содержит только `А` и `М`.
4. Приложение голосом просит найти одну из двух букв.
5. Позиции `А` и `М` должны перемешиваться, чтобы не формировать позиционное угадывание.
6. Ребёнок выбирает крупную кнопку.
7. Приложение показывает спокойную обратную связь.
8. Записывается попытка: target, selected, correctness, response time, timestamp, sessionId, levelId.
9. После 10 вопросов показывается простой результат.
10. Данные сохраняются после перезапуска приложения.
11. Проект собирается без ошибок и unit tests проходят.
12. Владелец проводит M1 acceptance test на реальном телефоне.

## Gate перед M2

Не переходить к полноценному LearningEngine v1, пока владелец не проверил M1 на телефоне и не подтверждены:

- понятный интерфейс;
- корректный TTS;
- комфортный темп;
- понятная реакция на ошибку;
- отсутствие позиционного угадывания;
- сохранение истории.

## Что НЕ делать следующим шагом

Не начинать одновременно весь алфавит, карту из 33 уровней, speech recognition ребёнка, сложную статистику, персонажей и Google Play.

Использовать `NEXT_TASK.md` как точное задание для Gemini/Android Studio и `docs/DEFINITION_OF_DONE.md` как критерий приёмки.
