# NEXT_TASK.md — M1: первый запускаемый вертикальный срез

## Цель

Создать первый рабочий Android-билд App_ABC, который можно запустить на телефоне и проверить на двух буквах.

## Техническое задание

Создай Android-приложение в текущем репозитории.

Стек: Kotlin, Jetpack Compose, Material 3, Gradle Kotlin DSL, package `com.dronrome1245.appabc`, Room, ViewModel + StateFlow, Android TextToSpeech через маленький wrapper/service.

### Экран 1 — Главная

- название «Буквы»;
- кнопка «Начать»;
- подпись «Уровень 1 · А М»;
- без регистрации и профиля.

### Экран 2 — Упражнение

- две крупные кнопки `А` и `М`;
- сверху нейтральный текст «Найди букву» без отображения ответа;
- кнопка повтора голосовой инструкции;
- TTS произносит целевое название буквы;
- 10 вопросов;
- нельзя выдавать одну и ту же цель более двух раз подряд;
- после ошибки спокойно показать правильный ответ, без жизней/наказаний;
- ошибочную букву вернуть через несколько вопросов, а не обязательно сразу.

### Данные попытки

Сохранять: targetLetter, selectedLetter, isCorrect, responseTimeMs, timestamp, levelId.

### Экран 3 — Результат

Показать правильных X/10, строки по А и М, кнопку «Ещё раз» и кнопку «На главную».

### Тесты

- выбор следующего вопроса вынести из Compose в чистый Kotlin-класс;
- unit-тест на запрет длинной серии одной цели;
- unit-тест на возврат ошибочной буквы;
- выполнить доступные unit tests и debug build.

1. Обновить `PROJECT_STATUS.md`.

3. Не переходить к уровню 2 до проверки UX владельцем.
