# NEXT_TASK.md — M1 Owner Acceptance

GitHub tracking: **Issue #1 — `[Feature] M1 — первый запускаемый вертикальный срез`**.

## Единственный следующий шаг

**Ручной смоук-тест владельцем на устройстве: прохождение 1 сессии из 10 вопросов на буквах А/М и сохранение статистики.**

## Что сделать владельцу

1. Получить актуальную fix-ветку/PR и открыть проект в Android Studio.
2. Запустить приложение на реальном Android-устройстве.
3. Убедиться, что на главном экране показаны только `А` и `М`.
4. Нажать «Начать тренировку».
5. Пройти все 10 вопросов.
6. Проверить TTS, смену позиций букв и спокойную реакцию на ответ.
7. Проверить результат после десятого вопроса.
8. Закрыть приложение, открыть снова и убедиться, что история попыток сохранена.
9. Сообщить результат Owner Acceptance.

## Статус gate

- `LOCAL_ANDROID_RUNTIME_STATUS: PENDING_OWNER_RUN`
- `OWNER_ACCEPTANCE_STATUS: PENDING`
- M1 до этого момента не считается завершённым.
- Переход к M2 запрещён.

## Android Studio Agent

Для обычного Run Agent Mode не нужен.

Использовать Android Studio Agent только если при ручном запуске возникнет конкретный локальный Gradle/SDK/runtime-сбой либо ошибка TTS/Audio, требующая IDE/Logcat-контекста.
